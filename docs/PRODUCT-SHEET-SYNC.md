# 商品試算表同步

Google 試算表的 `mycafe` 分頁與網站資料庫的商品雙向同步,約每分鐘一次。

## 運作方式

- 在試算表改商品 → 約 1 分鐘內寫入網站資料庫。
- 在後台改商品 → 約 1 分鐘內寫回試算表。
- 兩邊同一列都改過 → 該列「同步狀態」顯示 ⚠ 衝突,不會覆蓋;選取該列,用選單「喝三杯咖啡」選擇以表格或網站為準。

## 欄位

`slug`、`分類`(咖啡豆 / 沖煮器具)、`狀態`(上架 / 下架)、每個語言(zh-Hant、en、ms-MY、id-ID)的 `名稱`、`簡介`、`描述`,以及 `售價`(新台幣,元)。

- 空白格子不會蓋掉網站現有內容。
- 新增商品:在表格新增一列,至少填 `slug` 與 `zh-Hant 名稱`。圖片與規格請到後台設定。
- 不同步刪除;要下架請把 `狀態` 改成 `下架`。
- 若商品有多個規格且價格不同,表格的 `售價` 不會覆蓋,請到後台修改。
- `同步狀態` 與 `_base` 欄由系統維護,請勿手動修改。

## 設定(擁有者)

1. 網站端:Cloudflare Pages secret `SYNC_TOKEN`(`openssl rand -hex 32` 產生)。
2. 試算表:擴充功能 → Apps Script → 新增檔案,貼上 `scripts/apps-script/mycafe-sync.gs`,執行 `mycafeSetup`,輸入網站網址與同樣的金鑰。
3. 金鑰只存在 Cloudflare 與 Apps Script 的指令碼屬性,不要放進 repo。
